**Склейка файлов для Windows 1.0.0**: соединение и разрезание файлов, а также сборка одного APK из split-APK.

**Установка.** `Sklejka-Setup-*.exe` ставит программу только для текущего пользователя, права администратора не нужны. Можно взять портативный `Sklejka-Portable-*.zip`. Exe без цифровой подписи, поэтому SmartScreen покажет предупреждение: «Подробнее», затем «Выполнить в любом случае».

**Соединение**
- Форматы частей: .001/.002 (HJSplit, Total Commander, 7-Zip), .part1, файл.ext.1, файл_1.ext, .gsd, .aa/.ab, .7z.001, .zip.001, .apk.001.
- Файлы и папки можно перетащить в окно. Если выбрать одну часть, остальные найдутся в той же папке.
- Части сортируются по номерам. Порядок меняется перетаскиванием. Программа предупреждает о пропущенных и лишних частях и о частях с нестандартным размером.
- Соединение идёт потоком с прогрессом, скоростью и оставшимся временем. Можно отменить и потом продолжить с места остановки. Свободное место проверяется заранее.
- Результат проверяется по CRC32, MD5 и SHA-256 и сверяется с .crc (Total Commander), .sfv, .md5, .sha256.
- Zip можно распаковать прямо в программе.
- Многотомные .part1.rar и .z01 программа распознаёт и предлагает открыть в архиваторе: такие тома простым соединением не собрать.

**APK.** Файлы .apks (SAI, bundletool), .xapk (APKPure), .apkm (APKMirror) или папка с base.apk и split_config.*.apk собираются в один устанавливаемый APK.
- Склейку делает APKEditor, он же чистит манифест от признаков split-APK.
- Подпись: apksigner, схемы v1, v2, v3. Ключ свой или собственный ключ программы.
- Подпись проверяется после сборки. Если телефон подключён по USB, можно сразу установить через adb.
- Для зашифрованного .apkm выводится понятное сообщение.

**Разрезание** на части 10 МБ … 4 ГБ или своего размера, с .crc.

**Проводник.** Пункт «Склеить» в меню для .001, .apks, .xapk, .apkm и запись в «Открыть с помощью». Регистрируется только в HKCU.

Сторонние компоненты: APKEditor (Apache-2.0), apksigner (Apache-2.0), OpenJDK (GPLv2 + Classpath Exception), Android platform-tools adb.
